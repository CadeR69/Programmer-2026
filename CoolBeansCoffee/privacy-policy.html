Privacy Policy

Effective date: October 31, 2026

CoolBeans Coffee is a made-up coffee shop, and this website is a practice project. There is nothing to buy and no account to create. This page explains the little information that is collected when you visit.

1. Information you give us

None. The website has no forms, sign-ups or payments, and it does not set cookies.

2. Visitor counts

We count visits with GoatCounter, an analytics service that does not use cookies or store anything in your browser. It records the page you viewed, the site that linked you here, your browser, operating system, language and screen width, and your approximate location, such as your country. It does not store your IP address, and it does not share the data with anyone else.

To tell a new visit from a repeat one, GoatCounter briefly links your visit to a random code, held in memory for up to 8 hours and then forgotten. GoatCounter is run from Ireland and stores its data on servers in Finland and Germany. For details, see GoatCounter's privacy policy.

3. Hosting

This website is hosted on GitHub Pages. When you visit, GitHub logs your IP address for security purposes, as described in the GitHub General Privacy Statement.

4. Your choices

You can block the visitor counter with a content blocker. The website works the same without it.

5. Changes to this policy

If this policy changes, the new version will be posted on this page with a new effective date.

6. Contact

This website is run by its developer as a practice project. To ask about this policy, open an issue on the project's GitHub page.
